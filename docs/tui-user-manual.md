## 概要

Alopex CLI の TUI は、ターミナル上でインタラクティブにデータを操作するためのインターフェースです。

### 主な機能

- **Results TUI**: SQL クエリや各種コマンドの結果をテーブル形式で表示
- **Admin TUI**: データベース管理操作を統合的に行う管理コンソール

### 動作要件

- TTY 環境（対話式ターミナル）が必要
- macOS, Linux, Windows で動作
- 最小ターミナルサイズ: 80x24

## 起動方法

### 自動 TUI モード（デフォルト）

TTY 環境では、コマンド実行時に自動的に TUI が起動します。

```bash
# SQL クエリ実行 → Results TUI が起動
alopex sql "SELECT * FROM users"

# KV 一覧 → Results TUI が起動
alopex kv list

# 引数なし → Admin TUI が起動
alopex
```

### バッチモード（TUI 無効化）

```bash
# --batch フラグで TUI を無効化
alopex --batch sql "SELECT * FROM users"

# --output フラグでも TUI が無効化される
alopex --output json sql "SELECT * FROM users"

# パイプ出力時は自動的にバッチモード
alopex sql "SELECT * FROM users" | jq .
```

### プロファイルを使用したリモート接続

```bash
# プロファイル指定でリモートサーバーに接続
alopex --profile prod sql "SELECT * FROM users"

# Admin TUI でリモート管理
alopex --profile prod
```

## Results TUI（クエリ結果表示）

### 画面構成

Results TUI は 3〜4 つの領域で構成されています:

```
┌─────────────────────────────────────────────────────────┐
│ Command (任意)                                          │
│  - 実行中のコマンド/クエリを表示                         │
├─────────────────────────────────────────────────────────┤
│ Results (テーブル領域)                                  │
│  - クエリ結果をテーブル形式で表示                       │
│  - スクロール、検索、選択が可能                         │
├─────────────────────────────────────────────────────────┤
│ Detail (詳細領域) - Enter キーでトグル                  │
│  - 選択行の詳細を JSON/YAML 形式で表示                  │
├─────────────────────────────────────────────────────────┤
│ Status (ステータスバー)                                 │
│  - 接続情報、行数、状態、操作ヒントを表示               │
└─────────────────────────────────────────────────────────┘
```

### 基本操作

#### ナビゲーション

| キー | 動作 |
|------|------|
| `j` / `↓` | 下に移動 |
| `k` / `↑` | 上に移動 |
| `h` / `←` | 左にスクロール（列が多い場合） |
| `l` / `→` | 右にスクロール（列が多い場合） |
| `g` | 先頭行にジャンプ |
| `G` | 末尾行にジャンプ |
| `Ctrl+d` | 半ページ下にスクロール |
| `Ctrl+u` | 半ページ上にスクロール |
| `PageDown` | 1 ページ下にスクロール |
| `PageUp` | 1 ページ上にスクロール |

#### 詳細表示

| キー | 動作 |
|------|------|
| `Enter` | 詳細パネルの表示/非表示を切り替え |
| `J` | 詳細パネルを下にスクロール |
| `K` | 詳細パネルを上にスクロール |

詳細パネルでは、選択中の行データを以下の形式で表示します:
- JSON 形式
- YAML 形式

#### 検索

| キー | 動作 |
|------|------|
| `/` | 検索モードを開始 |
| `n` | 次のマッチに移動 |
| `N` | 前のマッチに移動 |
| `Enter` | 検索を確定 |
| `Esc` | 検索をキャンセル |
| `Backspace` | 検索文字を削除 |

検索はインクリメンタル検索で、入力中にリアルタイムでマッチが更新されます。
マッチしたセルは黄色でハイライトされます。

#### その他

| キー | 動作 |
|------|------|
| `?` | ヘルプオーバーレイの表示/非表示 |
| `a` | Admin TUI を起動（利用可能な場合のみ） |
| `q` / `Esc` | TUI を終了 |

### ステータスバーの読み方

```
Connection: local | Rows: 100 | Status: ready | q: quit | ?: help | /: search
```

- **Connection**: 接続先（`local` または プロファイル名）
- **Rows**: 表示中の行数
- **Status**: 現在の状態（`ready`, `processing`）
- 操作ヒント: 利用可能なキーバインド

## Admin TUI（管理コンソール）

Admin TUI は、データベースのライフサイクル管理を統合的に行う管理コンソールです。

### 起動方法

```bash
# 引数なしで起動
alopex

# プロファイル指定で起動
alopex --profile prod

# server サブコマンドから起動（引数なし）
alopex server
```

### 画面構成

Admin TUI は 4 つの領域で構成されています:

```
┌──────────────────────┬──────────────────────────────────────────────┐
│     Resources        │                   Actions                    │
│     (リソースツリー) │                   (アクション一覧)          │
│                      ├──────────────────────────────────────────────┤
│                      │                   Detail                     │
│                      │                   (詳細/入力フォーム)        │
├──────────────────────┼──────────────────────────────────────────────┤
│                      │                   Status                     │
│                      │                   (実行結果/プレビュー)      │
├──────────────────────┴──────────────────────────────────────────────┤
│ Status Bar (ステータスバー)                                         │
└─────────────────────────────────────────────────────────────────────┘
```

### フォーカス領域

Admin TUI には 3 つのフォーカス領域があります:

1. **Table（左側）**: リソースツリー
2. **Detail（右上）**: アクション一覧と入力フォーム
3. **Status（右下）**: 実行結果のプレビュー

フォーカスの移動:
- `h` / `←`: 左のフォーカス領域へ移動
- `l` / `→`: 右のフォーカス領域へ移動

### Resources（リソースツリー）

左側のリソースツリーには、以下のリソースが表示されます:

- **SQL Tables**: テーブルとカラムの一覧
- **Columnar Segments**: カラムナストレージのセグメント一覧
- **KV Keys**: Key-Value ストアのキー一覧

#### リソースツリーの操作（Table フォーカス時）

| キー | 動作 |
|------|------|
| `j` / `↓` | 下に移動 |
| `k` / `↑` | 上に移動 |
| `g` | 先頭にジャンプ |
| `G` | 末尾にジャンプ |
| `Ctrl+d` | 半ページ下にスクロール |
| `Ctrl+u` | 半ページ上にスクロール |
| `/` | リソース検索を開始 |
| `e` | Detail に移動してフィールド編集を開始 |
| `r` | Detail に移動して raw モードへ切り替え |
| `Enter` | リソースを選択（フォームに反映） |
| `R` | リソース一覧を更新 |

### Actions（アクション）

利用可能なアクション:

| アクション | 説明 |
|-----------|------|
| **Read / List** | データの参照・一覧取得 |
| **Create** | 新規データの作成 |
| **Update** | 既存データの更新 |
| **Delete** | データの削除 |
| **Archive** | データのアーカイブ（長期保存） |
| **Restore** | アーカイブからの復元 |
| **Backup** | バックアップの作成 |
| **Export** | データのエクスポート |

#### アクションの操作（Detail フォーカス時）

| キー | 動作 |
|------|------|
| `j` / `↓` | 次のアクションを選択 |
| `k` / `↑` | 前のアクションを選択 |
| `Tab` | 次の入力フィールドに移動 |
| `Shift+Tab` | 前の入力フィールドに移動 |
| `e` | 現在のフィールドを編集 |
| `o` | フィールドの選択肢一覧を表示 |
| `r` | raw パラメータモードに切り替え |
| `Enter` | アクションを実行 |

### ターゲット

Admin TUI では、以下のターゲットに対して操作を実行できます:

| ターゲット | 説明 |
|-----------|------|
| **SQL** | SQL テーブルへのクエリ |
| **KV** | Key-Value ストアの操作 |
| **Vector** | ベクトルインデックスの操作 |
| **HNSW** | HNSW インデックスの管理 |
| **Columnar** | カラムナストレージの操作 |

ターゲットは Resources の選択内容に合わせて自動で切り替わります。\
SQL テーブルを選べば SQL、KV Keys セクション/キーを選べば KV、Columnar Segments を選べば Columnar が選択されます。

### 入力フォーム

各アクションには、ターゲットに応じた入力フォームが表示されます。

#### Guided Mode（ガイドモード）

フィールドごとに値を入力するモードです:

```
Input: guided fields (Tab to move, e to edit, o to list)
> Query *: SELECT * FROM users
  Table: users
  Columns: id,name,email
```

- `*` が付いたフィールドは必須
- `(o)` が付いたフィールドは選択肢一覧が利用可能

#### Raw Mode（生パラメータモード）

`r` キーで切り替え。パラメータを直接入力します:

```
Input: raw parameters (press r to switch)
Params: query="SELECT * FROM users"
Example: query="SELECT * FROM table"
```

### 入力編集モード

#### フィールド編集（EditingField）

`e` キーで開始。フィールドの値を編集します。

| キー | 動作 |
|------|------|
| 文字キー | 文字を入力 |
| `Backspace` | 文字を削除 |
| `Enter` / `Esc` | 編集を終了 |

#### 選択オーバーレイ

`o` キーで開始。選択可能なフィールドで候補一覧を表示します。

| キー | 動作 |
|------|------|
| `j` / `↓` | 下に移動 |
| `k` / `↑` | 上に移動 |
| `g` | 先頭にジャンプ |
| `G` | 末尾にジャンプ |
| `/` | 候補をフィルタリング |
| `Enter` | 選択を確定 |
| `Esc` | 選択をキャンセル |

### Status（実行結果）

アクション実行後、Status 領域に結果が表示されます。

#### Status フォーカス時の操作

| キー | 動作 |
|------|------|
| `j` / `↓` | 下にスクロール |
| `k` / `↑` | 上にスクロール |
| `g` | 先頭にジャンプ |
| `G` | 末尾にジャンプ |
| `Ctrl+d` | 半ページ下にスクロール |
| `Ctrl+u` | 半ページ上にスクロール |

### 使用例

#### SQL クエリの実行

1. `alopex` で Admin TUI を起動
2. 左の Resources から テーブルを選択（Enter）
3. Actions で「Read / List」を選択
4. Query フィールドに `SELECT * FROM users` と入力（`e` で編集）
5. `Enter` で実行
6. Status 領域に結果が表示される

#### KV データの作成

1. Resources の `KV Keys` セクションを選択（ターゲットが KV に切替）
2. Actions で「Create」を選択
3. Key フィールドに `app/config` と入力
4. Value フィールドに `{"debug": true}` と入力
5. `Enter` で実行

#### リソース検索

1. Table フォーカス（左側）に移動
2. `/` キーで検索開始
3. 検索語を入力（例: `user`）
4. マッチするリソースがフィルタリングされる
5. `Enter` で検索確定、`Esc` でキャンセル

## トラブルシューティング

### "TUI requires a TTY" エラー

**原因**: 非 TTY 環境（パイプ、リダイレクト等）で TUI を実行しようとした

**解決策**:
- `--batch` フラグを使用してバッチモードで実行
- `--output` フラグで出力形式を指定
- 対話式ターミナルで実行

```bash
# バッチモードで実行
alopex --batch sql "SELECT * FROM users"

# 出力形式を指定
alopex --output json sql "SELECT * FROM users"
```

### 行が表示されない

**原因**: ターミナルの高さが不足している

**解決策**:
- ターミナルウィンドウを拡大
- クエリで取得する列を減らす
- `--max-rows` や `--limit` で行数を制限

### 検索が遅い

**原因**: データセットが大きすぎる

**解決策**:
- `WHERE` 句でデータをフィルタリング
- テキスト量の多い列を除外
- `--limit` で取得行数を制限

### Admin TUI でリモートリソースが表示されない

**原因**: リモート接続ではリソース一覧の取得に制限がある

**解決策**:
- ローカル接続を使用
- raw パラメータモードで直接クエリを入力

### キーが効かない

**原因**: 入力モードやフォーカス領域が異なる

**解決策**:
- ステータスバーで現在のモードとフォーカスを確認
- `Esc` で通常モードに戻る
- `h`/`l` でフォーカスを移動

### ターミナルが乱れた状態で終了した

**原因**: 異常終了により端末状態が復元されなかった

**解決策**:
- `reset` コマンドを実行してターミナルをリセット
- または新しいターミナルセッションを開始

```bash
reset
```
