# Development performance evidence

These reports retain the measured results, acceptance decisions, source identities,
artifact digests and workload limits. Execution-host specifications, CPU assignments,
absolute working paths and raw native profiles are retained in private evidence.
`$PRIVATE_PATH` tokens represent private execution inputs.

Recorded source and artifact digests identify the original runs. Redacting host
metadata from these report copies does not rerun measurements or qualify a release.
