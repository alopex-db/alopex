# Alopex CLI TUI 画面遷移図

このドキュメントでは、Alopex CLI の TUI（Text User Interface）における画面遷移とモード切り替えを説明します。

## 全体構成

```
┌─────────────────────────────────────────────────────────────────────┐
│                        Alopex CLI Entry                             │
│                                                                     │
│   ┌─────────────────┐    ┌─────────────────┐    ┌───────────────┐  │
│   │  alopex <cmd>   │    │    alopex       │    │ alopex --batch│  │
│   │  (with args)    │    │  (no args)      │    │   <cmd>       │  │
│   └────────┬────────┘    └────────┬────────┘    └───────┬───────┘  │
│            │                      │                     │          │
│            ▼                      ▼                     ▼          │
│   ┌─────────────────┐    ┌─────────────────┐    ┌───────────────┐  │
│   │   Results TUI   │    │   Admin TUI     │    │  Batch Output │  │
│   │  (Query Mode)   │    │  (Console Mode) │    │   (stdout)    │  │
│   └─────────────────┘    └─────────────────┘    └───────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

## UI モード決定フロー

```
                    ┌─────────────────┐
                    │   CLI 起動      │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ --output 指定?  │
                    └────────┬────────┘
                             │
              ┌──────────────┴──────────────┐
              │ Yes                         │ No
              ▼                             ▼
    ┌─────────────────┐           ┌─────────────────┐
    │   Batch Mode    │           │ --batch 指定?   │
    │   (出力優先)    │           └────────┬────────┘
    └─────────────────┘                    │
                              ┌────────────┴────────────┐
                              │ Yes                     │ No
                              ▼                         ▼
                    ┌─────────────────┐       ┌─────────────────┐
                    │   Batch Mode    │       │   TTY 環境?     │
                    │   (明示指定)    │       └────────┬────────┘
                    └─────────────────┘                │
                                          ┌───────────┴───────────┐
                                          │ Yes                   │ No

```

          ┌─────────────────────────┼─────────────────────────┐

## Results TUI から Admin TUI への遷移

```
┌─────────────────────────────────────────────────────────────────────┐
│                         Results TUI                                 │
│                                                                     │
│   SQL クエリ結果を表示中...                                         │
│                                                                     │
│   ┌─────────────────────────────────────────────────────────────┐   │
│   │ # │ id │ name  │ created_at │                               │   │
│   │ 1 │ 10 │ alice │ ...        │                               │   │
│   │ 2 │ 11 │ bob   │ ...        │                               │   │
│   └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│   Status: ... | a: admin                                            │
│                               │                                     │
│                               │ 'a' キー押下                        │
└───────────────────────────────┼─────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                          Admin TUI                                  │
│                                                                     │
│   管理コンソールが起動                                              │
│   (Results TUI は終了)                                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 終了フロー

```
           ┌─────────────────┐
           │    TUI 実行中   │
           └────────┬────────┘
                    │
          ┌─────────┴─────────┐
          │ q/Esc             │ a (admin)
          ▼                   ▼
  ┌─────────────────┐  ┌─────────────────┐
  │ クリーンアップ  │  │ Admin 起動要求  │
  │ (raw mode解除)  │  │ フラグ設定      │
  │ (画面復元)      │  └────────┬────────┘
  └────────┬────────┘           │
           │                    │
           ▼                    ▼
  ┌─────────────────┐  ┌─────────────────┐
  │   終了          │  │ クリーンアップ  │
  │   (exit 0)      │  │ 後、Admin TUI   │
  └─────────────────┘  │ を起動          │
                       └─────────────────┘
```
